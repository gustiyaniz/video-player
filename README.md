# FydeOS Video Player

Fitur subtitle:
- Tampilan putih tebal dengan outline hitam seperti subtitle acara TV.
- Pengaturan ukuran, posisi, warna, font, outline, dan background tersimpan otomatis.
- Ikon subtitle dapat memuat file .srt/.vtt secara manual ketika video sedang terbuka.
- Buka File mendukung pemilihan video dan subtitle sekaligus; jika namanya sama, subtitle dimuat otomatis.
- Contoh: pilih Film.mkv bersama Film.srt atau Film.vtt.
- Volume terakhir dan status mute disimpan, lalu dipulihkan saat aplikasi dibuka kembali.
