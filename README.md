# FydeOS Video Player

Fitur subtitle:
- Tampilan putih tebal dengan outline hitam seperti subtitle acara TV.
- Pengaturan ukuran, posisi, warna, font, outline, dan background tersimpan otomatis.
- Tombol Buka Folder mencari subtitle .srt/.vtt dengan nama dasar yang sama secara otomatis.
- Contoh: Film.mkv akan memakai Film.srt atau Film.vtt dari folder yang dipilih.
- Buka File tetap mendukung pemilihan video dan subtitle sekaligus.
